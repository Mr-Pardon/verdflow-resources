## 介绍与预览图

以主体草坪与收边草坪形成连续覆盖，再按需叠加中心主景、组团灌木与外围点缀。
适合花坛、草坪及小型景观绿地；关闭点景用途后，也可单独铺设草坪。

本条目面向飞渡 DTS 种植流程；策略本身不绑定特定模型库。
角色及构图关系如下：

| 角色 | 构图作用 |
| --- | --- |
| 主体草坪 | 覆盖地块内部的主要草坪区域 |
| 收边草坪 | 以较密的点位补齐边缘覆盖 |
| 中心主景 | 点景组团的中心植被 |
| 组团灌木 | 围绕主景组织低矮植被 |
| 外围点缀 | 在组团周围提供更松散的变化 |

主要参数包括主体草坪间距、点景组团密度与主景出现概率。
各用途可以独立启停，覆盖是否连续还取决于植被模型大小与缩放。
包内带弧形内凹花坛的参数示例，便于观察参数变化，不代表任意实际地块的最终效果。

## 换成你的策略时

- 名称与版本要和实际 VFS 声明一致；更新已有策略时附上原条目链接和本次变化。
- 说明适合的地块形态、角色关系、关键参数、实际测试过的环境及已知限制；未验证的平台不要写成已支持。
- 对算法依赖、额外文件或运行限制据实说明，不需要为投稿新增客户端逻辑或重新设计包格式。
- 采用其他项目代码或素材时列出出处与许可；不要把示例的 Apache-2.0 当成默认授权。
- 可直接提供公开可获取的 VFS 链接，维护者审核后整理 Release、包身份和校验值；投稿不自动获得执行信任。

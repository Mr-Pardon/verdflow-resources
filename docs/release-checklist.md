## 仍需维护

- 本仓库网站代码与文档的明确许可，独立于每项资源许可。
- 配套 PAK 的真实下载、安装和模型就绪性验收。本次仅登记维护者提供的外链，不下载 PAK。
- 主站资源中心导航入口。资源发布无需重新构建 Site，但首次入口仍需在 Site 配置。
- 后续种植方案、资源版本和投稿的审核；不要用测试包填充列表。

静态 CI 和导入校验不代表策略代码安全审计、执行沙箱或真实 DTS 场景验收。

## 配置

本地默认 SITE_BASE=/。项目 Pages 使用 /<repository>/，工作流从真实仓库名生成。
VITE_RESOURCE_REPOSITORY 可覆盖实际 GitHub 仓库 HTTPS 地址；默认使用本项目正式仓库。
SITE_BASE 改变后必须重建再验证。自定义域名或用户主页部署需调整 workflow 中的 base。

部署失败保持之前的线上版本。不会自动上传附件、信任策略或修改客户端资源。
上线后仓库更名或 URL 变更需同时核对 Site 导航和历史链接。

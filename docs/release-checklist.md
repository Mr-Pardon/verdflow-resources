# 资源中心上线清单

## 本地实现已具备

- 独立的分类列表、搜索筛选、详情、README、历史版本与撤回展示。
- 静态记录校验、内容快照生成和附件大小 / SHA-256 核验命令。
- Issue 投稿表单、PR 核对清单、Pages 工作流。
- 本地与项目子路径、桌面与手机、失败恢复的自动化测试。

## 公开前仍需完成

- 确认远端仓库名，创建仓库并启用 GitHub Pages / GitHub Actions。
- 确认本仓库代码和文档的许可。每项资源独立保留作者与许可。
- 核对品牌素材、文档截图的分发权限与公开内容。
- 收集真实资源：包内声明、README、封面、版本、关联、作者许可与 PAK 外链。
- 人工验证包内容、平台可用性和策略来源。静态 CI 不是代码安全审计或执行沙箱。
- 先上传固定版本 Release 附件，再合入对应正式记录；运行下载核验。
- 完成线上 Pages 深链接、下载和投稿入口验收，再向主站添加导航。

正式公开前没有资源也可以部署真实空目录；不要用测试包填充列表。

## 配置

本地默认 SITE_BASE=/。项目 Pages 使用 /<repository>/，工作流从真实仓库名生成。
VITE_RESOURCE_REPOSITORY 为实际 GitHub 仓库 HTTPS 地址；本地未配置时不显示伪造投稿链接。
SITE_BASE 改变后必须重建再验证。自定义域名或用户主页部署需调整 workflow 中的 base。

部署失败保持之前的线上版本。不会自动上传附件、信任策略或修改客户端资源。
上线后仓库更名或 URL 变更需同时核对 Site 导航和历史链接。

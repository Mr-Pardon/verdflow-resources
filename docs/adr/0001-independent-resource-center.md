# ADR-0001: 独立资源中心与按需内容加载

日期：2026-10-22。状态：已接受。

## 决策

Resources 仓库同时维护资源中心的通用页面、资源条目和发布工具。
官网与用户手册仍由 verdflow-site 管理，仅通过链接连接资源中心。

- web 持有 Vue 页面、浏览状态与 Markdown 渲染；不持有具体资源内容。
- entries 持有资源元数据、每版本 README 及轻量图片；不提交交换包或 PAK。
- scripts 静态校验输入并生成可按需请求的目录和内容快照。
- VFA/VFS/VFP 使用固定版本的 GitHub Releases 附件；PAK 仅为外链。
- Pages 托管页面和 JSON/Markdown/图片，不需要运行时数据库或后端。

资源列表只加载摘要目录；详情按需加载单条记录与所选版本 README。
README 不执行 HTML、Vue 或脚本。只有部署完成后内容才对外更新。
详情采用查询参数地址，直接访问和刷新不依赖服务端重写。

## 保留的产品边界

不修改 VFA/VFS/VFP 格式，不引用产品 Core，不负责本地策略兼容解析、信任或执行。
来源资产库是追溯关系，不是方案使用的新前提；实际平台模型仍须由平台侧提供。
收录、下载和作者署名不自动授予执行信任。静态 CI 不执行投稿中的生成器。

## 取舍

独立维护部署和视觉规范，避免资源发布牵动手册构建。纯客户端详情的搜索收录和分享
摘要有限；将来可由相同内容生成静态摘要，不增加另一份手工介绍。

完整设计、当前实现范围与上线条件分别见资源中心设计、资源格式和发布清单。

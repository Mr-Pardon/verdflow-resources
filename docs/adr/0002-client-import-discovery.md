# ADR-0002：客户端方案导入发现协议

状态：Accepted，2026-10-29。经用户授权启用新增端点，并收录现有全部已发布资源。

## 决策

配合 VerdFlow ADR-0060，资源中心提供受控策略发现和可选来源资产库发现，不成为运行时
包管理器。客户端 SystemHost 负责本地兼容解析、下载授权、真实包校验、导入及取消清理。
网页及索引不执行策略，不赋予信任，不要求安装来源资产库或外部 PAK。

实际附件通过 VerdFlow 的公共包读取器静态检查，派生 package-inspections.json；它绑定
条目与真实附件的身份、版本、归档摘要、策略内容指纹以及方案的依赖/来源事实。构建时
与已审核 entries 交叉检查。该记录不是签名或代码审计，不导入产品 Core，也不新增包格式。

新增 starter-resources-v2.json（schemaVersion=2）和 import-index.json（schemaVersion=1）。
旧 starter-resources.json 永远保持原 v1，只包含资产库与策略。两版推荐选择来自同一份
collections/starter.json，v1 显式投影，而不是由旧客户端静默忽略新类型。

导入索引记录固定 Release 附件、真实内容指纹和包身份；来源资产按 target_type/catalog_id
识别。网站关系只供页面展示，不能替代包内事实。资产和方案只提供当前推荐快照，策略
提供已发布版本以供客户端同 major 兼容选择；未知归属、同身份版本歧义拒绝构建。

## 发布与验证

完成开发客户端与真实包的隔离导入验证后，经独立发布授权，构建同时输出三个端点，
不再依赖试运行开关。新增端点不替换旧端点，旧协议不写入方案。
本次推荐选择包括现有 2 个资产库、3 个策略和 4 个方案；旧清单投影为 5 项 VFA/VFS。
新增协议已可独立部署；已有客户端仍读取 v1，方案推荐需使用后续支持 v2 的产品版本。
客户端便携发布包验证仍由产品发版流程负责，不因静态端点部署而视为已通过。

验收覆盖旧端点协议兼容、v2 方案与来源事实、缺失/过期检查记录、撤回资源、重复身份、
产品解析器与网站构建器契约，以及真实包在隔离空白 Library 中导入。普通网站构建、
单元测试与浏览器回归继续执行。检查记录更新和推荐清单调整都需要独立内容审核。

# 影像面片树

面向地形影像与大面积林地的种植预设，使用“层次生态群落”策略形成自然疏密变化。
仅启用 **主景植被**，搭配 Weekly_Library 中的 **3 种面片树**；铺底植被已关闭，
本方案不生成草坪。

![影像面片树在 DTS 中的种植效果](media/cover.png)

图为使用场景中的效果示例。地形、影像、水体和周边场景不随 VFP 分发；
实际效果仍取决于地块、采样高程、模型资源与观察视角。

## 植被搭配

| 用途 | 植被 | 缩放 | 用途内权重 |
| --- | --- | --- | --- |
| 主景植被 | 面片树_01_Low | 100%-300% | 66% |
| 主景植被 | 面片树_02_Low | 100%-300% | 22% |
| 主景植被 | 面片树_03_Low | 100%-180% | 12% |

权重用于各候选的随机分配，不保证每次生成的精确数量比例。
缩放范围为方案保存的随机缩放配置，实际大小仍取决于 DTS 中模型的原始尺寸。
方案还保留了三种植被的参考半径与高度，供参数示例等展示使用。

## 已保存的效果参数

| 参数 | 配置 |
| --- | --- |
| 主景覆盖比例 | 80% |
| 主景植被间距 | 16.5 米 |
| 宏观斑块尺度 | 30 米 |

铺底植被处于关闭状态，方案保留的铺底覆盖率 85%、间距 3.4 米不用于本次铺底生成。
如需补充地表层，可在配置中启用铺底角色并选择相应植被。

## 开始使用

1. 导入并信任关联的“层次生态群落”策略；本方案保存于 2.2.2。
2. 通过配套 PAK 入口准备 DTS 模型资源。
3. 下载本页 VFP，在 VerdFlow“种植方案”中导入“影像面片树”。
4. 在工作台或实时种植面板选择“预设方案”，选用该方案并指定种植区域。
5. 根据地块尺寸与观察距离，微调主景间距、覆盖比例、斑块尺度或植被缩放。

来源资产库为 **Weekly_Library**（公开标识 `weekly_library`），可用于追溯植被和继续选材。
VFP 已携带模型引用、权重、缩放和参数快照，使用方案不额外要求安装来源资产库，
DTS 中仍需有对应模型。面片树适合与场景视距和展示需求一起评估，不代表近景精细树模。

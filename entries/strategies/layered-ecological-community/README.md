# 层次生态群落

通过共享密度场组织铺底与主景，形成连续但有疏密变化的植被群落。
适合大面积绿地、林地与地形植被铺设。

![层次生态群落的角色与构图示意](media/roles.webp)

## 两种植被用途

| 用途 | 构图作用 |
| --- | --- |
| 铺底植被 | 形成低矮植被层，提供地表支撑范围 |
| 主景植被 | 在铺底范围内形成主景斑块；关闭铺底后可独立覆盖整个地块 |

可以只启用其中一种用途，每种用途也可以搭配多种植被。
策略只负责空间分布；具体模型、权重、缩放由植被搭配或种植方案决定。

## 调整效果

- 覆盖率控制支持生成植被的面积比例，不等同于实际树冠覆盖率。
- 植被间距控制点位疏密；宏观斑块尺度控制群落的连续与破碎程度。
- 包内包含角色示意与参数示例，支持在 VerdFlow 中观察参数变化。

## 使用与版本

下载 VFS 后导入策略库，核对来源并确认信任，再选择资产进行搭配。
不要求使用某一个特定资产库，也不随包分发植被模型。

**2.2.2** 优化噪波格点缓存与覆盖率阈值统计预算。角色、参数与主要构图关系保持不变，
但少量边缘点可能与 2.2.1 不同，不承诺不同版本逐点一致。
同主版本方案的自动兼容由新版 VerdFlow 客户端处理；已有项目冻结的策略快照不随下载更新。
